Compose バンドルの作り方

手元で docker compose up が通る構成を、そのまま VM 1 台として配布できます。 VM の中で Docker が動き、ports: で公開したポートが VM の IP で待ち受けます （例: 192.168.181.200:80）。

手順

  1. 手元で compose プロジェクトを用意し動作確認する
  2. 付属ツール bento-pack を実行する（クローン不要・root 不要。認証なしで取得できる）。 ファイルに保存して実行する場合: 
    curl -fsSL {{ request.url.scheme }}://{{ request.url.netloc }}/static/tools/bento-pack -o bento-pack
chmod +x bento-pack
./bento-pack --bundle ./my-ctf -o my-ctf.bundle.tar
    ファイルを残さず直接実行する場合: 
    curl -fsSL {{ request.url.scheme }}://{{ request.url.netloc }}/static/tools/bento-pack | bash -s -- --bundle ./my-ctf -o my-ctf.bundle.tar
  3. 新規プロジェクト作成で「Compose バンドル」を選び、tar をアップロード
  4. サーバがネットワークなしのビルド用 VM の中で ext4 を組み立て、ready になれば起動可能

注意点

  • 各サービスに image: を指定する（build: のみは不可。pack が build/pull してイメージを同梱する）
  • macvlan/ipvlan ネットワークや固定 IP（ipv4_address）は使えない（VM の IP は 1 つ）。公開は ports: で行う
  • ゲスト OS 側にフラグや設定ミスを仕込みたい場合は、プロジェクト直下の overlay/ に置く （例: overlay/root/flag.txt → VM の /root/flag.txt）
  • 名前付きボリュームや DB の初期化は VM 起動のたびにまっさらから始まる（CTF に好適）
