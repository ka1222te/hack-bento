Compose バンドルの作り方

手元で docker compose up が通る構成を、そのまま VM 1 台として配布できる形式です。 VM の中で Docker が動き、ports: で公開したポートが VM の IP で待ち受けます （例: 192.168.181.200:80）。

1. compose プロジェクトを用意する

手元で docker compose up が通る状態まで動作確認しておく。

2. bento-pack でバンドルを作る

付属ツール bento-pack を実行する。
ファイルに保存して実行する場合
curl -fsSLk {{ request.url.scheme }}://{{ request.url.netloc }}/static/tools/bento-pack -o bento-pack
chmod +x bento-pack
./bento-pack --bundle ./my-ctf -o my-ctf.bundle.tar
ファイルを残さず直接実行する場合
curl -fsSLk {{ request.url.scheme }}://{{ request.url.netloc }}/static/tools/bento-pack | bash -s -- --bundle ./my-ctf -o my-ctf.bundle.tar

3. プロジェクトを作成する

プロジェクト作成ページに戻り、作成した tar をアップロードする。

注意点

  • build: のみは不可のため、作成したイメージが分かるように image: もあわせて付ける
  • macvlan/ipvlan ネットワークや固定 IP（ipv4_address）は使えない（VM の IP は 1 つ）。公開は ports: で行う
  • ゲスト OS 側にフラグや設定ミスを仕込みたい場合は、プロジェクト直下の overlay/ に置く （例: overlay/root/flag.txt → VM の /root/flag.txt）
