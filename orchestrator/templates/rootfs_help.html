rootfs の作り方

HackBento は Firecracker microVM で環境を起動します。登録するプロジェクトには 「OS イメージ」と「Compose バンドル」の 2 形式があり、作りたい環境に応じてどちらかを選びます。

📦 Compose バンドル

推奨・手軽

手元で docker compose up が通る構成を、そのまま VM 1 台として配布します。 複数サービス（Web + DB + LB など）を 1 台で動かしたい場合はこちら。

💾 OS イメージ

中で Docker を使わない 1 台

ゲストカーネルと rootfs をそれぞれ指定して VM を作ります。 1 つのサービス / OS を直接作る、カーネル CVE を扱う場合はこちら。

作り方を見る →

どちらを選ぶか

  • 複数のサービス（Web + DB + LB など）を 1 台で動かす → Compose バンドル
  • 1 つのサービス / OS を直接作る、カーネル CVE を扱う → OS イメージ
